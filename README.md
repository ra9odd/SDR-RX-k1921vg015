# SDR-RX-k1921vg015
SDR Receiver based on  K1921VG015 NIIET chip with Teylo mixer. BlueBird-VG015 board.
Наброски SDR приемника на базе 1921вг015 со смесителем Тейло (fst3253), пока тестовый вариант прошивки. Задуман, как попытка uSDX на отечественном чипе. В коде нет реализации управления по i2c  синтезатора si5351, на макете он внешний. Тактовая частота - 50 МГц. Смещение в спектре постоянное 8 КГц. Нет выбора полосы (только USB). Реализованы простые: АРУ, ФНЧ - 3 кГц. Вся работа основана на   прерывании от  16-ти битного, 8-ми канального сигма-дельта АЦП с частотой семплинга 62.5 КГц, все каналы которого работают параллельно, что очень удобно. АЦП заполняет пинг-понг буфер для данных I Q, который обрабатывает функция process_adc_data() в бесконечном цикле в main(). Лишнее из кода еще не убрано.
Выход звука через ШИМ.
